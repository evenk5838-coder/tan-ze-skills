# 谭泽的 Skill 工具箱

围绕中文写作、课程笔记与 AI 产品决策整理的个人 Skill。希望把实际工作中的思考方法，变成能够重复使用、也能继续修改的流程。

## 有哪些 Skill

| Skill | 适合什么任务 | 入口 |
|---|---|---|
| `ze-essays` · 泽的随笔 | 生活随笔、私人回忆与情感表达；从真实细节写起，保留自然长句、口语和自嘲 | [查看说明](skills/ze-essays/SKILL.md) |
| `tan-ze-writing` · 谭泽写作 | AI 产品体验、行业观察、科普和局部改稿；先写顺中文，再建立有依据的判断 | [查看说明](skills/tan-ze-writing/SKILL.md) |
| `project-initiation-report` · 立项报告 | 梳理竞品、需求优先级、MVP、投入和风险，制作 AI 产品立项报告；支持新项目与迭代规划 | [查看说明](skills/project-initiation-report/SKILL.md) |
| `note-assistant` · 笔记助手 | 整合课堂录音转写与手记，按知识主题梳理，保留原话高亮与图表；先审阅、确认后入库 | [查看说明](skills/note-assistant/SKILL.md) |

随笔任务可选 `ze-essays`；行业文章或跨文体改稿可选 `tan-ze-writing`。通常选择一项即可。立项 Skill 面向决策文档，不负责写 PRD。课程录音和手记整理、确认稿入库使用 `note-assistant`。

## 如何使用

下载本仓库，将 `skills/` 下需要的完整文件夹放入支持 Skill 的工具对应目录。在 Codex 中可放入个人 Skill 目录，再在聊天中调用：

```text
请用 $ze-essays 润色下面这段随笔，只使用我提供的事实和感受。

请用 $tan-ze-writing 修改这篇 AI 产品体验文章的开头，其他部分不改。

请用 $project-initiation-report 和我先梳理立项要求，再根据现有调研材料制作报告。

请用 $note-assistant 整理这些课堂材料，保留我的原话高亮，先交我审阅，确认后再入库。
```

这是一组指令与参考文档，不是独立运行的软件，也不附带模型服务或 API 密钥。笔记助手不包含个人课程原文、私有飞书地址或固定的本机知识库路径；飞书写入需要环境提供已授权工具，Obsidian 入库需要本地文件访问能力。联网检索、Word、HTML 等任务需要运行环境提供相应工具；不同工具对 Skill 和元数据的支持可能不同。立项 Skill 沿用仅显式调用的设置。

## 公开版的范围

本仓库只包含方法、模板、检查清单与必要配置。私人随笔原文、对话改稿过程、具体作业案例及本机路径不在公开版中。

写作 Skill 保留个人表达取向，但公开版没有私人样本，不能据此保证复现某位作者。需要贴近自己的表达时，在当前任务提供愿意使用的素材或原稿即可，不必上传到公开仓库。

Skill 结构与引用已经检查；这些检查不代表所有模型和环境下的实际表现都已经验证。涉及市场、定价和产品状态的内容，应在使用时重新核实，保留事实、测算与假设的区别。
