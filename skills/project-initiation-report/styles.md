# 文风选项

在第 0 步沿用用户已明确的文风，未确定时再让用户选择。所有文风都要遵守：结论先行、用数字和原话说话、证据标来源。

1. **大白话汇报风（默认推荐）**：结论先行，口语化短句，关键数字加粗，每节开头一句话说清"这节要说明什么"，少用黑话。适合内部评审、向直属老板要资源。
2. **正式决策书风**：书面语，结构严谨，表格为主，措辞克制，"建议/待确认"表述规范。适合给管理层或跨部门正式审批。
3. **自然讲述风**：用具体问题、证据和取舍讲清来龙去脉，避免模型套话和商业黑话；不预设用户已安装其他 Skill。适合大范围读者或作品集展示。
4. **面试作品集风**：在大白话风基础上，每个关键决策旁加一句"为什么这么做、不那么做"，便于面试时讲取舍。适合课程作业与求职。
5. **极简一页纸**：只输出决策摘要 + 三问矩阵 + MVP 范围表 + 阶段闸门 + 风险，其余放附录。适合快速对齐方向。

用户也可以自定义描述文风。
