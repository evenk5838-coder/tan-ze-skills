# 笔记片段与高亮

下面是通用排版示例，不是真实课堂内容或固定目录。

```markdown
# 某日课程笔记

> [!important] 核心重点
> 先明确任务与约束，再选择能力，最后检查结果。

## 需求澄清

用户提出目标后，需要确定哪些条件已知，哪些缺失会影响下一步。

> [!personal-note] 我的笔记
> 这里放用户摘下的原话或关键词。

## 执行与验证

任务执行后，读取真实结果，再判断是否继续、修改或停止。
```

Obsidian 自定义 `personal-note` 的颜色取决于库的样式配置；已有黄色类型时复用。其他环境用原生黄色高亮，不向用户展示标记代码。

只在必要时加解释或待核实块。可以自然写“这里需要区分……”或“这个比例来自案例，尚缺原始报表”，不必每段标注文字类别。

来源和归档入口放文末。个人理解和课后总结留空，不代写“我已理解”“我以后一定……”等反思。
