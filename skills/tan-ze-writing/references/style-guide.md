# 个人表达的校准方法

公开版不包含私人样文。需要贴近用户本人表达时，以其本轮主动提供的原稿、样文和明确反馈为依据；不要从作者姓名或 Skill 名称推断用户的职业、经历、口头语或感受。

- 先辨认文体和读者。行业体验文章需要对象、事实和判断；生活随笔可以顺着真实细节展开记忆。
- 找出样文里稳定的表达选择，例如叙述顺序、长短句节奏、口语程度和收尾方式。把它们当作可修正的判断，不从一篇文章推导永久规则。
- 只迁移表达方法，不迁移人物、地点、健康信息、对白、生活经历和独特意象。
- 改稿优先保留当前原稿的原意与有辨识度的细节；需要补事实时询问，不用修辞掩盖材料不足。
- 用户未提供样文时，按本 Skill 的自然中文原则处理，并明确这是依据现有素材完成的写作，不宣称已精准复现本人笔风。

私人参考材料只用于用户授权的当前任务；不要为完成写作而自动持久化或公开。
